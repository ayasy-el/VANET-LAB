# 📊 Data Analysis & Performance Metrics

This document explains the extraction of simulation output records, primary VANET routing evaluation metrics, and analysis scripts using Python and `opp_scavetool`.

---

## 1. Output Directory & File Formats

Simulation runs store telemetry records in **`vanet_aodv/results/`**:

- **Scalar Files (`*.sca`)**: Aggregate summaries computed at the end of a run (total packets transmitted/received, mean RTT latency, standard deviation, min, and max).
- **Vector Files (`*.vec`)**: Discrete time-series event records (per-packet RTT variations, throughput over time).
- **Vector Index Files (`*.vci`)**: Binary indices generated by OMNeT++ to accelerate time-series lookups.

---

## 2. Core VANET Evaluation Metrics

Four primary metrics assess the effectiveness of the AODV protocol in vehicular networks:

### A. Packet Delivery Ratio (PDR)
The proportion of successfully delivered application packets from source to destination:

$$\mathbf{\text{PDR} = \left( \frac{\sum \text{Packets Received by Destination}}{\sum \text{Packets Transmitted by Source}} \right) \times 100\%}$$

- **VANET Context**: PDR reflects route durability amidst high vehicular mobility and network partitioning.

### B. End-to-End Latency & Round-Trip Time (RTT)
The transit duration for packets traversing multiple vehicle hops:

$$\mathbf{\text{RTT}_{\text{avg}} = \frac{1}{N} \sum_{i=1}^{N} (t_{\text{reply}, i} - t_{\text{send}, i})}$$

- **VANET Context**: Initial packets encounter higher latency due to the *Route Discovery* phase (RREQ/RREP exchange). Subsequent packets traverse the established route with single-digit millisecond latency.

### C. Network Throughput
The effective application data payload delivered to the receiver per unit time:

$$\mathbf{\text{Throughput (kbps)} = \frac{\sum \text{Bytes Received} \times 8}{(t_{\text{end}} - t_{\text{start}}) \times 1000}}$$

### D. Normalized Routing Overhead (NRO)
The ratio of AODV routing control packets to successfully delivered data packets:

$$\mathbf{\text{NRO} = \frac{\sum (\text{RREQ} + \text{RREP} + \text{RERR} + \text{HELLO})}{\sum \text{Data Packets Received}}}$$

- **VANET Context**: High NRO values indicate excessive 5.9 GHz channel consumption by routing protocol overhead.

## 3. Data Extraction with `opp_scavetool`

OMNeT++ includes `opp_scavetool` for command-line exporting to CSV:

```bash
cd vanet_aodv/results

# 1. Export all scalar summaries to CSV:
opp_scavetool x -o scalars_summary.csv *.sca

# 2. Export specific time-series vectors (e.g., RTT) to CSV:
opp_scavetool export -F csv -o rtt_data.csv -f 'name =~ "*rtt*"' *.vec
```

## 4. Automated Python Parser Script

You can inspect `.sca` files using the following lightweight Python script:

```python
#!/usr/bin/env python3
import sys
import re

def parse_sca(filepath):
    sent = 0
    received = 0
    rtt_mean = 0.0

    with open(filepath, 'r') as f:
        for line in f:
            if "packetSent:count" in line:
                match = re.search(r'count\s+(\d+)', line)
                if match:
                    sent += int(match.group(1))
            elif "packetReceived:count" in line:
                match = re.search(r'count\s+(\d+)', line)
                if match:
                    received += int(match.group(1))
            elif "rtt:mean" in line:
                match = re.search(r'mean\s+([\d\.]+)', line)
                if match:
                    rtt_mean = float(match.group(1))

    pdr = (received / sent * 100.0) if sent > 0 else 0.0
    print("=" * 45)
    print(f" Result Summary: {filepath}")
    print("=" * 45)
    print(f" Packets Sent     : {sent}")
    print(f" Packets Received : {received}")
    print(f" PDR              : {pdr:.2f} %")
    if rtt_mean > 0:
        print(f" Mean RTT         : {rtt_mean * 1000:.2f} ms")
    print("=" * 45)

if __name__ == "__main__":
    if len(sys.argv) > 1:
        parse_sca(sys.argv[1])
    else:
        print("Usage: python3 parse_results.py results/<filename>.sca")
```
